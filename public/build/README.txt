Put the packaged Unreal Engine 4 HTML5 / WebAssembly output in this folder.

Expected files (names match window.UE4_HOST_CONFIG.buildName in ../index.html,
default "UE4Game"):

  UE4Game.js
  UE4Game.wasm
  UE4Game.data
  favicon.ico      (optional)

The host does not need anything else from the package: index.html, styles.css
and the loading screen in ../ are already provided by this repository.
